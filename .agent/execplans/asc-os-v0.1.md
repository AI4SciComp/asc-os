# ASC OS v0.1 execution plan

Implement the runbook's deterministic research substrate in tested vertical
slices: safe schema/model foundations; atomic storage/scaffolding; context
restriction; cover/overlap/claim/evidence checks; lifecycle/gluing/artifacts;
CLI; stdio MCP; pilot; documentation, packaging, and CI. Each slice receives
direct tests and a focused commit before publication.

The implementation remains pre-release, provider-neutral, local-first, and
Python-only. It never executes skill/manifest content or mutates Git.
