# ADR 0002: topos-inspired model

Status: accepted, 2026-08-29.

ASC OS uses bounded contexts, restriction, declared covers and overlaps, and
gluing as practical organizing analogies. A cover expresses declared coverage,
overlap checks establish specified compatibility, and a gluing manifest records
integration prerequisites. None of these surfaces claims a formal topos model,
automatic proof, semantic completeness, or global correctness.
