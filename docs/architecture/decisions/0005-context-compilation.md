# ADR 0005: context compilation

Status: accepted, 2026-08-29.

Context compilation is deterministic restriction. It includes project policy,
the selected context, explicit upstream summaries, active decisions, required
claim/evidence summaries, relevant overlaps, applicable instructions, declared
source excerpts only when requested, source hashes, and stable Git provenance.

The common content model is harness-neutral. Codex and Claude adapters change
presentation only. Root instruction files are never overwritten; installation
of a missing concise entrypoint is explicit. Size limits fail with section
sizes and never silently truncate equations or acceptance criteria.
